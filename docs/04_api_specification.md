# API Specification

**Author (persona):** GenAI Developer
Base URL: `http://localhost:8000` (local) — see `infra/k8s/service.yaml` for cluster URL

Auth: header `X-API-Key: <key>` (demo key in `.env.example`; replace with OAuth2/OIDC or cloud IAM auth in production).

## GET /health
Liveness/readiness probe used by Kubernetes.

Response `200`:
```json
{"status": "ok", "vector_store": "chroma", "documents_indexed": 12}
```

## POST /ingest
Trigger ETL + chunk + embed for all files under the configured source directory (or a provided list of paths).

Request:
```json
{"source_paths": ["data/sample_docs/genai_platform_overview.txt"]}
```

Response `200`:
```json
{
  "documents_processed": 1,
  "chunks_indexed": 14,
  "manifest": [
    {"document_id": "genai_platform_overview", "checksum": "a1b2c3", "chunks": 14}
  ]
}
```

## POST /query
Hybrid-RAG grounded question answering.

Request:
```json
{"question": "How does the hybrid retriever combine dense and lexical scores?", "k": 4, "alpha": 0.6}
```

Response `200`:
```json
{
  "answer": "The hybrid retriever fuses scores as alpha * dense_score + (1 - alpha) * bm25_score ...",
  "citations": [
    {"chunk_id": "genai_platform_overview::chunk_3", "score": 0.83, "source": "genai_platform_overview.txt"}
  ],
  "retrieval_strategy": "hybrid",
  "latency_ms": 142
}
```

## POST /agent/run
Multi-step agentic research over the knowledge base.

Request:
```json
{"goal": "Compare the retrieval latency budget with the fine-tuning experiment's accuracy gain and summarize the tradeoff.", "max_steps": 6}
```

Response `200`:
```json
{
  "answer": "...",
  "steps": [
    {"step": 1, "action": "retrieve", "args": {"query": "retrieval latency budget"}, "observation": "NFR-1 states P95 < 3s ..."},
    {"step": 2, "action": "retrieve", "args": {"query": "fine-tuning accuracy gain"}, "observation": "Hit-rate@5 improved from 0.61 to 0.78 ..."},
    {"step": 3, "action": "finish", "args": {}, "observation": null}
  ],
  "steps_used": 3,
  "max_steps": 6
}
```

## GET /metrics
Prometheus exposition format — request counts, latency histograms, retrieval hit-rate gauge, token-usage counter.

## Error format (all endpoints)
```json
{"error": {"code": "VALIDATION_ERROR", "message": "question must not be empty"}}
```

Full machine-readable OpenAPI schema is auto-generated by FastAPI at `/openapi.json` and interactive docs at `/docs` when the service is running.
